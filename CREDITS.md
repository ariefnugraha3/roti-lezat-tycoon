## Asset provenance (GDD 111.3)

The game ships **no** imported art, model, audio or font files. Every runtime asset
is generated by scripts in this repository:

| Asset | Generated by | Notes |
|---|---|---|
| 3D equipment, furniture, rooms | `procedural/meshes/equipment_factory.gd`, `procedural/meshes/room_factory.gd`, `procedural/meshes/mesh_factory.gd` | Primitive meshes and `SurfaceTool`, parameterized by tier. |
| Bread and pastries | `procedural/meshes/bread_factory.gd` | Profiles per recipe `visual_profile_id`; bake shade and freshness tint. |
| Chibi characters (player, staff, customers, drivers, couriers, Pak Lurah) | `procedural/meshes/character_factory.gd` | Parameterized bodies, faces, hair, outfits and props. |
| Animation and particles | `procedural/animation/anim_system.gd`, `procedural/animation/fx.gd` | Trigonometric locomotion, tweens, `CPUParticles`. |
| UI panels, buttons, icons | `procedural/ui/ui_factory.gd`, `procedural/ui/icon_canvas.gd` | `StyleBoxFlat` and `_draw()` vector icons. |
| Music, SFX, ambience | `audio/audio_generator.gd` | Runtime synthesis from oscillators, noise, envelopes and sequencing per `data/catalog/audio_events.json`. |
| Application icon (`icon.svg`) | `tools/generate_icon.gd` | Regenerate with `godot --headless --path . --script res://tools/generate_icon.gd`. |
| Text font | Godot's built-in default font (`ThemeDB.fallback_font`) | Ships inside the engine; no font file is bundled (GDD 111.2). |
