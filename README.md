# Roti Lezat Tycoon

A cozy bakery management tycoon for Web (itch.io, HTML5) and Android, built with
Godot 4.7-stable (GDScript only, Compatibility renderer). You run a bakery: bake in
the morning, sell from 08:00 to 18:00, fulfil RotiFood delivery orders, hire staff,
and grow from a garage to a landmark bakery. Every visual and sound is generated in
code, and the game runs fully offline.

- Design spec (the only authority): `docs/gdd-roti-lezaat-tycoon-ai-ready-v3.1-final.md` (GDD v3.1).
- Architecture: `docs/ARCHITECTURE.md` · Save format: `docs/SAVE_SCHEMA.md`.
- GDD compliance checklist: `docs/GDD_COMPLIANCE.md`.
- Credits and licenses: `CREDITS.md`, `LICENSES.md`. Platform limitations: `KNOWN_LIMITATIONS.md`.

## Requirements

- Godot **4.7.2-stable** Standard (not .NET). Export templates for 4.7.2 are needed only
  for exporting.
- For Android exports: OpenJDK 17, Android SDK Platform 35 and Build-Tools 35.0.1,
  NDK r28b, CMake 3.10.2 (GDD 128.2), configured in Godot's Editor Settings.

The commands below use a `G` variable for the console build of Godot. Adjust the path
to your installation:

```bash
G='D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'
```

## Open and run

```bash
"$G" --headless --path . --import   # first time, or after adding a class_name
"$G" --path .                       # open the editor
"$G" --path . res://scenes/main.tscn # run the game
```

On Web, the first screen asks for a tap before starting audio, as browsers require.

## Test

The harness is custom and needs no addons (GDD 107). Always run tests as **scenes**,
so the autoloads exist:

```bash
"$G" --headless --path . res://tests/test_runner.tscn                     # every suite
"$G" --headless --path . res://tests/test_runner.tscn -- --skip-long      # skip the soaks
"$G" --headless --path . res://tests/test_runner.tscn -- --only=TEST_SAVE # by ID prefix; --id=X for one exact ID
"$G" --headless --path . res://tools/compile_check.tscn                   # every script compiles
```

- A test fails on any failed assertion and on any engine or script error logged while
  it runs.
- The runner exits with code 1 if any test fails and writes `user://test_report.json`.
- The soak tests (`TEST_LONGRUN_100/500/1000`) take from tens of minutes to hours.
- Regenerate the golden save fixture only for intended gameplay changes: add
  `--only=TEST_SAVE_001 --update-fixtures`, then review the diff.

## Release validation

```bash
"$G" --headless --path . res://tools/release_validator.tscn             # full release gate
"$G" --headless --path . res://tools/release_validator.tscn -- --quick  # skip tests and exports
```

The validator implements GDD 133. It checks the catalogs, strings, source hygiene,
forbidden assets, the offline rule, the export presets, the location layouts, a
headless boot and Tier 1 day, the profiles, the golden save, the required tests and
the exports. It exits with 0 only when every rule passes. `--quick` always reports
the gate as closed.

## Export

Presets live in `export_presets.cfg` and contain no signing secrets:

```bash
mkdir -p build/web build/android
"$G" --headless --path . --export-release "Web" build/web/index.html
"$G" --headless --path . --export-debug "Android Debug APK" build/android/roti-lezat-tycoon-debug.apk
"$G" --headless --path . --export-release "Android Release AAB" build/android/roti-lezat-tycoon.aab
```

- **Web:** single-threaded, so itch.io needs no cross-origin isolation. Upload the
  contents of `build/web/` as an HTML5 game.
- **GitHub Pages:** `.github/workflows/deploy-web.yml` exports the Web build with the
  official Godot 4.7.2 (downloads checked against `SHA512-SUMS.txt`) and deploys it.
  Once, set *Settings → Pages → Build and deployment → Source* to **GitHub Actions**.
  Then push, open the *Actions* tab, choose **Deploy Web ke GitHub Pages** and press
  **Run workflow**. The game appears at `https://<user>.github.io/<repo>/`. It runs
  only when started by hand, so a push never publishes by accident.
- **Android release:** supply the keystore outside the repository, for example with
  the `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER` and
  `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD` environment variables. Never commit it
  (GDD 128.4).
- Package ID: `com.rotilezattycoon.game`; landscape only; no INTERNET permission.

## Project rules

- 100% procedural visuals: no image, model, audio or font files. `icon.svg` is
  generated by `tools/generate_icon.gd`.
- Every player-facing string is English and lives in `data/catalog/strings_en.json`.
  Code uses `Tx.t(key)`.
- All tuning lives in `data/catalog/*.json`, validated at boot. Do not hard-code
  balance numbers.
- Saves: three profiles in `user://saves/`, atomic writes with one backup generation.
